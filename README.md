# 📖 Overview

**Rock Paper Scissors** is a modern web-based implementation of the classic hand game where players compete against a computer opponent.

Built using **HTML5**, **CSS3**, and **JavaScript**, the project focuses on creating an engaging and responsive user experience while applying fundamental programming concepts such as conditional logic, random number generation, event handling, and DOM manipulation.

The application instantly evaluates every round, updates scores dynamically, and provides immediate visual feedback, making gameplay simple, interactive, and enjoyable across desktop and mobile devices.

# 🏗️ Project Architecture

The application follows a simple client-side architecture.

```
User Interaction
        │
        ▼
Select Rock / Paper / Scissors
        │
        ▼
Generate Random Computer Choice
        │
        ▼
Compare Choices
        │
        ▼
Determine Winner
        │
        ▼
Update Scores
        │
        ▼
Display Result
        │
        ▼
Play Again / Reset
```

# 🎮 Game Rules

| Player Move | Wins Against |
|-------------|--------------|
| 🪨 Rock | ✂️ Scissors |
| 📄 Paper | 🪨 Rock |
| ✂️ Scissors | 📄 Paper |

---

# ⚙️ Game Workflow

1. The player selects Rock, Paper, or Scissors.
2. The computer randomly chooses its move.
3. Both choices are compared.
4. The winner is determined based on the game rules.
5. Scores are updated instantly.
6. A result message is displayed.
7. The player can continue playing or reset the game.
